# Portofolio React

Website portofolio pribadi yang dibuat dengan React dan Vite.

## Menjalankan proyek

Pastikan Node.js dan npm sudah terpasang, lalu jalankan dari folder proyek:

```bash
npm install
npm run dev
```

Buka alamat lokal yang ditampilkan Vite di terminal. Untuk membuat build produksi:

```bash
npm run build
npm run preview
```

## Menyesuaikan konten

- Ubah nama, perkenalan, dan informasi kontak di `src/App.jsx`.
- Sesuaikan daftar proyek pada array `projects` dan keahlian pada array `skills` di file yang sama.
- Ubah warna, tata letak, dan tipografi di `src/style.css`.
- Judul dan deskripsi halaman ada di `index.html`.

Konten proyek dan identitas pada halaman ini adalah contoh; ganti dengan informasi dan karya Anda sendiri sebelum dipublikasikan.
